# Backend — Rent Car AI

Node.js + TypeScript API. All backend implementation, package manifests, configuration, Supabase migrations, tests, and server-only environment examples must remain in this directory.

Planned responsibilities:
- Supabase PostgreSQL connection and migrations.
- Private Supabase Storage integration.
- Inspection and photo metadata API.
- Claude Vision comparison service.
- Validation, authorization, ownership checks, and normalized results.

Use server-side environment variables. Never expose Supabase service-role or Anthropic credentials to the frontend.

Backend implementation is tracked in `.blueprint/tasks/TASK-001-backend-supabase.md`, TASK-003, and TASK-004.
